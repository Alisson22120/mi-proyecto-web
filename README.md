# EcoIdeas — Proyecto escolar

Sitio web sencillo hecho con Python y Flask para compartir ideas para cuidar el medio ambiente.

## Archivos
- `app.py`: aplicación Flask.
- `templates/index.html`: página principal.
- `static/estilos.css`: estilos visuales.
- `requirements.txt`: dependencia necesaria.

## Cómo ejecutarlo en tu computadora
1. Instala Python si todavía no lo tienes.
2. Abre una terminal en esta carpeta.
3. Ejecuta `pip install -r requirements.txt`.
4. Ejecuta `python app.py`.
5. Abre `http://127.0.0.1:5000` en tu navegador.

## Subirlo a GitHub
Crea un repositorio y usa **Add file → Upload files**. Sube los archivos y carpetas del proyecto, y pulsa **Commit changes**.
